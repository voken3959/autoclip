      Clipping setup

      1. 1

        Create a Twitch app

        In the Twitch developer console, register an application with client type Confidential and add this OAuth redirect URL.

      2. 2

        Add the keys to your server

        Set TWITCH_CLIENT_ID, TWITCH_CLIENT_SECRET and ADMIN_KEY in your host's environment settings, then redeploy.

      3. 3

        Connect your Twitch account

      4. 4

        Keep it connected after restarts

        Some hosts wipe saved files whenever the app restarts. Copy the refresh token and save it as TWITCH_CLIP_REFRESH_TOKEN so clipping keeps working.

      Enter the admin key
